# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Email **support@5sim.net** with the subject `5sim MCP security`, and include steps to reproduce. We aim to reply within 3 business days.

Never include your API key in a report. If a key may have leaked, rotate it at https://5sim.net/settings/security.

## Scope

- This MCP server (`@5sim-net/mcp`): the stdio and Streamable HTTP transports, and the tool input validation.
- Issues in the 5sim website or API itself: please report them through https://5sim.net/support.

## Supported versions

Only the latest released version gets security fixes.
